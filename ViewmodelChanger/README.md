# Viewmodel Changer

Sets where your gun sits on screen and its field of view, for each gun type.

In the mod's settings, each gun type has:

- Gun FOV
- Forward and Back
- Left and Right
- Up and Down

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
