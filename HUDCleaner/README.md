# HUD Cleaner

Hides the parts of the HUD you pick.

- Hide Entire HUD
- Hide Compass
- Hide Mission Panel
- Hide Health and Shield Bars
- Hide Ammo Panel
- Hide Grenade Panel
- Hide Skill Icon
- Hide Level Bar
- Hide Teammate Panels

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
