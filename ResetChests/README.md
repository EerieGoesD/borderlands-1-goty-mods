# Reset Chests

Shuts every red and white chest you have opened in this area, ready to be looted again.

## Settings

- **Reset Chests in This Area**: press it to shut the chests around you.
- **Reset Red Chests**: whether red chests are included.
- **Reset White Chests**: whether white chests are included.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
