# Vehicle Jump

Lets you jump while driving.

Space throws the vehicle upwards. You can change the key in the mod settings.

## Settings

- **Jump Height**: how hard the vehicle pushes off the ground.
- **Show jump height [DEBUG]**: prints how high the last jump went.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
