# Hide Full Pickups

Stops ammo you cannot carry from lighting up on the ground.

Anything that would say FULL loses its beam and its icon. The moment you spend some
ammo and can pick it up again, the beam comes back.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
