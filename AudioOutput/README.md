# Audio Output

Picks which audio device the game plays through, and switches it while the game is running.

The game picks a device when it starts and normally keeps it until you restart. The one
you pick here is used again every time the game starts.

## Settings

- **Audio Output Device**: the device the game plays through.
- **Apply**: moves the game's sound to the picked device.
- **Scan Devices**: looks again for devices, such as one plugged in after the game started.
- **Master Volume**: the volume of everything the game plays, whatever device it is on.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
