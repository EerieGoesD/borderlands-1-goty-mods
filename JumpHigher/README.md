# Jump Higher

Lets you jump higher than the game allows.

## Settings

- **Jump Height**: how hard you push off the ground. The game's own number is 630.
- **Show jump height [DEBUG]**: prints how high your last jump went.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
