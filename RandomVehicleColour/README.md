# Random Vehicle Colour

Gives every vehicle you spawn a random paint job.

## Settings

- **Pick at the terminal**: on, the colour is picked when you open the Catch-a-Ride,
  so you can see it before you spawn and click another swatch to overrule it. Off,
  the colour is picked when you press Spawn Vehicle.

## Install

Copy the mod's folder into `Borderlands\sdk_mods`, then start the game. It appears in
the SDK Mod Manager on the main menu.

Needs the [BL1 PythonSDK](https://github.com/bl-sdk/willow1-mod-manager).
